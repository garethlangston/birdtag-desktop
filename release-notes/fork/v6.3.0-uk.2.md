## Fixes in 6.3.0-uk.2

- **Species names containing "Kestrel" are displayed correctly again.** 6.3.0-uk.1 replaced every
  visible word "Kestrel" with the fork's name, so *Common Kestrel* appeared as "Common Birdtag"
  (and the British name *Kestrel* as "Birdtag"). The product name now comes from the source code
  (`analyzer/branding.json`), not a page-wide text replacement. Keywords were not affected; they
  were always `Birds|Kestrel|Falco tinnunculus`.
- **Settings no longer freezes when the extra models are missing.** The same text replacement
  looped forever on the "model not found" message, which lists the old
  `...\ProjectKestrel\models_extra` folder. Settings now shows which folders were searched and
  says it falls back to the North America bird model / SpeciesNet.

Install over 6.3.0-uk.1. Your settings and the files in
`%LOCALAPPDATA%\BirdtagDesktop\models_extra\` are kept.
