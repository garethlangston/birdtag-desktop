# Kestrel UK fork — notes (branch `uk-models`, phase 1)

A personal fork of [Project Kestrel](https://github.com/SanjaySoniLV/ProjectKestrel)
v6.3.0.0 that identifies **UK, European and world birds**, not just North
American ones. It writes species keywords in the same layout as the `birdtag` tool,
so digiKam and Lightroom keyword trees stay consistent.

## What changed

| Area | Change |
|---|---|
| Bird model | New `Inat21BirdSpeciesClassifier` (`analyzer/kestrel_analyzer/ml/bird_species_inat21.py`). It runs timm **EVA-02 Large, iNat21** (10,000 classes, 1,486 birds) through ONNX Runtime, using the same `ProviderCoordinator` / `ResilientOnnxSession` path, so DirectML→CPU fallback still works. The softmax covers only the selected region's birds. Preprocessing matches timm's (RGB, shorter side bicubic to 336, centre crop, CLIP mean/std). The classifier gets a **padded square crop** around the detector box (same as birdtag) instead of Kestrel's tight box, so the centre crop doesn't cut off heads or tails. |
| Regions | `analyzer/models/birds_inat21/` (generated by `tools/uk_models/build_inat21_region_lists.py`): `labels.txt` (10,000 iNat21 names in model order), `species.csv` (one row per bird class: BOU/IOC names, family, region flags) and `uk_birds.csv` (BOU British List, the source for UK names). **UK** = British List categories A/C without BBRC rarities, the same rule and `model_label` fallback as birdtag (258 model classes; 49 regular UK species are not in iNat21). **UK + rarities** adds 182. **Europe** = IOC regions `PAL`, `AO`, `Worldwide` plus UK (389 classes). **World** = all 1,486. |
| Names | The classifier reports **IOC catalogue names** ("European Robin"), so the species combobox, `lookup_birds` and everything else keyed on Kestrel's `birds_global.csv` keep working. Keywords use **BOU English names** ("Robin", "Grey Heron") through `kestrel_analyzer/bird_names.py`. BOU names are also added to the catalogue as aliases: typing "Robin" finds European Robin, and `lookup("Robin")` resolves. |
| Setting | Settings → Species & Region → **Bird identification model**: North America (original, still the default) / UK / Europe / World, plus **Include UK rarities (BBRC)**. Saved as `bird_model_region` and `bird_include_uk_rarities` in `settings.json`. The pipeline rebuilds the classifier when either changes; the change applies from the next analysis run. If the EVA-02 file is missing, Settings shows the folders searched, and the analysis status shows the same message while it falls back to the North America model for that run. |
| Keywords (XMP) | For each species result, confident = score ≥ 0.75 (Kestrel's default browse filter) or no model score supplied: `Xmp.lr.hierarchicalSubject` `Birds\|English` + `Birds\|English\|Latin`, `Xmp.digiKam.TagsList` `Birds/English/Latin` (+ parent), and flat `dc:subject` English + Latin. Below 0.75: only `Birds\|_Check\|English` (and `Birds/_Check/English`). Kestrel's rating, label, `kestrel:*` fields and `Kestrel\|…` subjects are unchanged. **Existing sidecars and embedded JPEG XMP are now merged, not replaced**: anything outside the `Birds` tree, plus other people's properties (e.g. `photoshop:City`), is kept. Like birdtag, Kestrel owns the `Birds\|…` tree and replaces it on each write. Sidecars made by other software still need the usual "overwrite?" confirmation. |
| Privacy | Crash reports, the app-open, install and completion pings, the startup version check and the `legal.json` check are off by default. See `PRIVACY-FORK.md`. |
| Tools | `tools/uk_models/export_eva02.py` (ONNX export + fp16 + parity check + README), `build_inat21_region_lists.py`, `compare_classifiers.py`. |

## Installing the bird model on Windows

The EVA-02 weights are **CC-BY-NC-4.0 (non-commercial only)**, so they are not in
git (`.gitignore` blocks `*.onnx` under `birds_inat21/`).

1. Get the ONNX files, either way:
   * **Copy** `eva02_large_inat21_fp16.onnx` (635 MB; best for the GTX 1050 Ti, 4 GB) and/or
     `eva02_large_inat21_fp32.onnx` (1.27 GB; used on CPU) plus `README.txt` from
     the exported folder (`kestrel-fork-models/` on the Linux box). Check the SHA256 values in
     `README.txt` (`certutil -hashfile <file> SHA256`).
   * **Or export them yourself** (needs about 4 GB RAM and Python 3.10+):
     ```
     py -m venv %USERPROFILE%\eva-export
     %USERPROFILE%\eva-export\Scripts\pip install torch timm huggingface_hub onnx onnxruntime onnxconverter-common pillow numpy
     %USERPROFILE%\eva-export\Scripts\python tools\uk_models\export_eva02.py --out D:\kestrel-models --images <folder of a few bird JPEGs>
     ```
     This downloads the timm model (~1.2 GB) once, exports fp32 (opset 17, legacy tracer),
     converts to fp16, checks both against timm, and writes `README.txt` with SHA256 values.
2. Put the `.onnx` file(s) in **`%LOCALAPPDATA%\ProjectKestrel\models_extra\`**
   (the folder that holds `settings.json`, plus `models_extra`). Kestrel also looks in
   `analyzer\models\birds_inat21\` and in `%KESTREL_MODELS_EXTRA_DIR%` if that is set.
3. Settings → Species & Region → Bird identification model → **UK**. The line under the
   setting confirms where the model was found. Re-analyse folders to get new species.

With **GPU** on, Kestrel uses fp16 if present (half the VRAM); on CPU it prefers fp32.

Full Kestrel CLI pipeline (MegaDetector mdv5a + SAM-HQ + species + quality) on the
birdtag test JPEGs. Each cell is the top-1 name Kestrel stores, then its confidence:

| image | North America (original) | UK (EVA-02 fp32) |
|---|---|---|
| robin | Rusty Blackbird 0.18 | European Robin 0.99 |
| bluetit | Black-capped Chickadee 0.87 | Eurasian Blue Tit 1.00 |
| greattit | Golden-winged Warbler 0.44 | Great Tit 1.00 |
| blackbird | Crested Myna 0.18 | Common Blackbird 1.00 |
| wren | Winter Wren 0.85 | Eurasian Wren 1.00 |

The UK run took 363 s for 9 images, against 129 s with the original model.
Unit tests: 960 passed (upstream baseline 913, plus 47 new). Integration/e2e/compat lane:
296 passed and 11 skipped, identical to upstream.

## Known limitations

* **DirectML not tested here** (the build machine is Linux, CPU only). The export uses the
  legacy TorchScript exporter at opset 17 with plain MatMul/Softmax attention, the same
  route Kestrel uses for its DirectML-safe `mdv1000-cedar` detector. If DirectML still
  fails, Kestrel's coordinator falls back to CPU automatically.
* **Speed**: EVA-02 Large is about 5 s per bird on 2 CPU cores (fp32). On a GTX 1050 Ti
  expect well under 1 s. It is far heavier than the original 300 px model.
* **Confidence is relative to the region**: the softmax only covers the selected
  region's species, so scores in UK mode are higher than World-mode scores for the same image.
* 49 regular UK species are not in iNat21 at all (see the build script's output), and
  10 iNat21 birds have no IOC catalogue entry (they keep the iNat name; lookups for them
  return nothing, as for any unknown name).
* "Europe" means the IOC Palearctic (`PAL`) + Atlantic (`AO`) + cosmopolitan species. IOC
  v15.1 has no finer Europe code, so some East-Asian Palearctic species are included.
* The confident/`_Check` split uses the model score sent from the culling window. A
  species changed by hand in the scene view is not flagged separately, so it keeps the
  original model score.
* The heron test image scores 0.69 in UK mode, so it gets `Birds|_Check|Grey Heron`.
  If that happens often, lower the threshold (`species_threshold` in
  `write_xmp_metadata`, default 0.75).
* The Kestrel database stores IOC names ("European Robin"); only keywords use BOU names.
* Kestrel replaces the `Birds|…` tree on each XMP write, as birdtag does. Manual digiKam edits
  under `Birds|` are overwritten if you write XMP from Kestrel afterwards.
