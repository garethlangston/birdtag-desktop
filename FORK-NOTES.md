# Birdtag Desktop: fork notes (branch `uk-models`, phases 1–3)

A personal fork of [Project Kestrel](https://github.com/SanjaySoniLV/ProjectKestrel)
v6.3.0.0 that identifies **UK, European and world birds**, not just North
American ones. It writes species keywords in the same layout as the `birdtag` tool,
so digiKam and Lightroom keyword trees stay consistent.

## What changed

| Area | Change |
|---|---|
| Bird model | New `Inat21BirdSpeciesClassifier` (`analyzer/kestrel_analyzer/ml/bird_species_inat21.py`). It runs timm **EVA-02 Large, iNat21** (10,000 classes, 1,486 birds) through ONNX Runtime, using the same `ProviderCoordinator` / `ResilientOnnxSession` path, so DirectML→CPU fallback still works. The softmax covers only the selected region's birds. Preprocessing matches timm's (RGB, shorter side bicubic to 336, centre crop, CLIP mean/std). The classifier gets a **padded square crop** around the detector box (same as birdtag) instead of Kestrel's tight box, so the centre crop doesn't cut off heads or tails. |
| Regions | `analyzer/models/birds_inat21/` (generated by `tools/uk_models/build_inat21_region_lists.py`): `labels.txt` (10,000 iNat21 names in model order), `species.csv` (one row per bird class: BOU/IOC names, family, region flags) and `uk_birds.csv` (BOU British List, the source for UK names). **UK** = British List categories A/C without BBRC rarities, the same rule and `model_label` fallback as birdtag (258 model classes; 49 regular UK species are not in iNat21). **UK + rarities** adds 182. **Europe** = IOC regions `PAL`, `AO`, `Worldwide` plus UK (389 classes). **World** = all 1,486. |
| Names | The classifier reports **IOC catalogue names** ("European Robin"), so the species combobox, `lookup_birds` and everything else keyed on Kestrel's `birds_global.csv` keep working. Keywords use **BOU English names** ("Robin", "Grey Heron") through `kestrel_analyzer/bird_names.py`. BOU names are also added to the catalogue as aliases: typing "Robin" finds European Robin, and `lookup("Robin")` resolves. |
| Setting | Settings → Species & Region → **Bird identification model**: UK (default since phase 2) / Europe / World / North America (original), plus **Include UK rarities (BBRC)**. Saved as `bird_model_region` and `bird_include_uk_rarities` in `settings.json`. The pipeline rebuilds the classifier when either changes; the change applies from the next analysis run. If the EVA-02 file is missing, Settings shows the folders searched, and the analysis status shows the same message while it falls back to the North America model for that run. |
| Keywords (XMP) | For each species result, confident = score ≥ 0.75 (Kestrel's default browse filter) or no model score supplied: `Xmp.lr.hierarchicalSubject` `Birds\|English` + `Birds\|English\|Latin`, `Xmp.digiKam.TagsList` `Birds/English/Latin` (+ parent), and flat `dc:subject` English + Latin. Below 0.75: only `Birds\|_Check\|English` (and `Birds/_Check/English`). Kestrel's rating, label, `kestrel:*` fields and `Kestrel\|…` subjects are unchanged. **Existing sidecars and embedded JPEG XMP are now merged, not replaced**: anything outside the `Birds` tree, plus other people's properties (e.g. `photoshop:City`), is kept. Like birdtag, Kestrel owns the `Birds\|…` tree and replaces it on each write. Sidecars made by other software still need the usual "overwrite?" confirmation. |
| Privacy | Crash reports, the app-open, install and completion pings, the startup version check and the `legal.json` check are off by default. See `PRIVACY-FORK.md`. |
| Tools | `tools/uk_models/export_eva02.py` (ONNX export + fp16 + parity check + README), `build_inat21_region_lists.py`, `compare_classifiers.py`. |

## Installing on Windows

**Birdtag Desktop** is this fork's working name; the name is set in `analyzer/branding.json`. It is
an unofficial fork of Project Kestrel and is not affiliated with it.

1. **Get the installer.** Either:
   * open <https://github.com/garethlangston/birdtag-desktop/releases> and download
     `BirdtagDesktop-<version>-Setup.exe` from the latest pre-release (e.g. `v6.3.0-uk.1`), or
   * download it from a build run: GitHub → **Actions** → *Fork Windows build (unsigned installer)* →
     a green run → **Artifacts** → `BirdtagDesktop-…-windows-installer` (a zip with the
     `.exe`; artifacts are kept for 30 days).
2. **SmartScreen:** the installer is **not code-signed**, so Windows shows *"Windows protected your
   PC"*. Click **More info → Run anyway**. It installs per user (no admin prompt) into
   `%LOCALAPPDATA%\Programs\Birdtag Desktop`. Choose *Install for all users* in the first dialog
   if you prefer.
3. **Models:** copy the extra model files into `%LOCALAPPDATA%\BirdtagDesktop\models_extra\`:
   * `eva02_large_inat21_fp16.onnx` (GPU) and/or `eva02_large_inat21_fp32.onnx` (CPU), for birds
   * the `bioclip-2\` folder (`config.json`, `image_encoder_fp32.onnx`, `embeddings\`), for
     reptiles, amphibians and insects

   Files you already put in `%LOCALAPPDATA%\ProjectKestrel\models_extra\` during phases 1–2
   are still found; there is no need to move them.
4. **Settings and data:** the fork keeps its own folder, `%LOCALAPPDATA%\BirdtagDesktop` (settings,
   logs, models_extra), so it never shares settings with an installed official Project Kestrel.
   On first start it copies `settings.json` once from `%LOCALAPPDATA%\ProjectKestrel` if that exists.
   Per-folder results (`.kestrel\` next to your photos) keep the same format.

The installer contains Kestrel's bundled models (SpeciesNet, MegaDetector, SAM-HQ, quality, the
NA bird model). Without the extra files the app falls back to the North America bird model
and SpeciesNet, and Settings shows where it looked.

## Phase 3: publishing as "Birdtag Desktop"

* Upstream's names, logos and Store identities are proprietary (upstream `assets/LICENSE`), so
  the fork uses its own name from `analyzer/branding.json`. That file is read by Python
  (`branding.py`: window title, data folder, user-facing messages), the UI (`js/brand.js` exposes
  `BRAND_NAME`/`BRAND_SHORT` for scripts and fills `data-brand*` markup once at load), the
  PyInstaller spec (exe name), the Inno Setup script and CI.
  Renaming the app means editing that one file and re-running `tools/branding/make_placeholder_art.py`.
* Placeholder artwork is generated (CC0). Store tiles, splash screen, MSIX manifest and branded
  screenshots were removed.
* Upstream hosted services are hidden and disabled (`upstream_services: false`): Perch,
  Cloud Compute, account sign-in, donation and feedback prompts, What's New, and telemetry to
  upstream's server.
* CI: `.github/workflows/fork-windows-build.yml` builds the unsigned installer on every push to
  `uk-models`, and on demand. Pushing a `v*` tag also publishes a GitHub pre-release with the
  installer attached. Upstream workflows (Store, macOS, App Store, cloud e2e) can only be run
  manually and are disabled in the fork's Actions settings.
* Internal identifiers stay as upstream: Python package `kestrel_analyzer`, the `.kestrel` results
  folder, the `kestrel:` XMP namespace and `Kestrel|…` keywords, the spec file name, and the
  keyring service name. They're not shown as the product name, and changing them would break
  compatibility with existing results and sidecars.

## Phase 4 (6.3.0-uk.2): fixes

* **"Common Kestrel" shown as "Common Birdtag".** uk.1's `brand.js` replaced the word "Kestrel"
  anywhere on the page. It now only fills explicit `data-brand` markup, and UI scripts use
  `BRAND_NAME`/`BRAND_SHORT`; upstream brand strings were changed in the source. Tests:
  `test_brand_strings.py` scans HTML/JS/Python for leftover brand strings (with an allowlist:
  comments, `[Kestrel]` log prefixes, `Kestrel|…` keywords, `.kestrel`/`kestrel:` identifiers,
  upstream-service text). It also checks that "Common/Lesser/American Kestrel" and the BOU
  "Kestrel" reach the picker data and keywords (`Birds|Kestrel|Falco tinnunculus`).
  `tools/ui_checks/brand_check.js` (node + jsdom) renders species cells with the real `brand.js`.
* **Settings froze when the extra models were missing.** uk.1's MutationObserver set a text node's
  value whenever it contained "Kestrel", even when nothing changed. Each assignment fired another
  mutation, so the "model not found" message (which lists `...\ProjectKestrel\models_extra`)
  looped forever and starved the UI. Reproduced headlessly with jsdom; fixed by removing the
  observer. The status messages now state the fallback, and Settings shows errors instead of
  hanging.

## Installing the bird model on Windows

The EVA-02 weights are **CC-BY-NC-4.0 (non-commercial only)**, so they are not in
git (`.gitignore` blocks `*.onnx` under `birds_inat21/`).

1. Get the ONNX files, either way:
   * **Copy** `eva02_large_inat21_fp16.onnx` (635 MB; best for the GTX 1050 Ti, 4 GB) and/or
     `eva02_large_inat21_fp32.onnx` (1.27 GB; used on CPU) plus `README.txt` from
     the exported folder (`kestrel-fork-models/` on the Linux box). Check the SHA256 values in
     `README.txt` (`certutil -hashfile <file> SHA256`).
   * **Or export them yourself** (needs about 4 GB RAM and Python 3.10+):
     ```
     py -m venv %USERPROFILE%\eva-export
     %USERPROFILE%\eva-export\Scripts\pip install torch timm huggingface_hub onnx onnxruntime onnxconverter-common pillow numpy
     %USERPROFILE%\eva-export\Scripts\python tools\uk_models\export_eva02.py --out D:\kestrel-models --images <folder of a few bird JPEGs>
     ```
     This downloads the timm model (~1.2 GB) once, exports fp32 (opset 17, legacy tracer),
     converts to fp16, checks both against timm, and writes `README.txt` with SHA256 values.
2. Put the `.onnx` file(s) in **`%LOCALAPPDATA%\BirdtagDesktop\models_extra\`**
   (the folder that holds `settings.json`, plus `models_extra`). Kestrel also looks in
   `analyzer\models\birds_inat21\` and in `%KESTREL_MODELS_EXTRA_DIR%` if that is set.
3. Settings → Species & Region → Bird identification model → **UK**. The line under the
   setting confirms where the model was found. Re-analyse folders to get new species.

With **GPU** on, Kestrel uses fp16 if present (half the VRAM); on CPU it prefers fp32.


## Phase 2: reptiles, amphibians, insects (BioCLIP 2) and keyword safety

| Area | Change |
|---|---|
| Model | **BioCLIP 2** (`imageomics/bioclip-2`, MIT, ViT-L/14, 224 px) image encoder in ONNX (`tools/uk_models/export_bioclip.py`). Zero-shot over GBIF species lists, using BioCLIP's "taxonomic + common name" prompts (`a photo of Animalia Chordata Reptilia Squamata Lacertidae Zootoca vivipara with common name Common Lizard.`). Text embeddings are precomputed at build time (`build_bioclip_embeddings.py`), so only the image encoder runs in Kestrel. The runtime (`kestrel_analyzer/ml/bioclip.py`) reads input size, mean/std, embedding size and logit scale from the model folder's `config.json`, so a BioCLIP 2.5 folder can be dropped in (export with `--model hf-hub:imageomics/bioclip-2.5-vith14 --name bioclip-2.5`; needs ~8 GB RAM). The ONNX session loads lazily, only when a reptile, amphibian or insect turns up, and uses the same GPU→CPU fallback coordinator. |
| Lists | `build_bioclip_lists.py` uses GBIF occurrence facets on human observations per region (UK = country GB, Europe = continent EUROPE, World = global). Reptiles are GBIF classes Squamata + Testudines + Crocodylia (GBIF has no Reptilia class); prompts still use class Reptilia. Minimum records: UK 5, Europe 20, World 50. Caps: insects UK 8,000, Europe 10,000, World 20,000 (most-recorded first). English names come from GBIF, tidied, with British names from `tools/uk_models/data/uk_wildlife_names.csv` for common species. `tools/uk_models/data/uk_exclude.csv` drops four species from the UK lists, with reasons. Two are taxonomic splits that compete with the British species (*Natrix natrix*, *Bufo spinosus*). Two are parasites whose photos mostly show their hosts (the toad fly *Lucilia bufonivora*, the ladybird wasp *Dinocampus coccinellae*); BioCLIP had labelled a toad and a ladybird with them. The UK and Europe lists are committed in `tools/uk_models/data/bioclip_lists/`. |
| Routing | SpeciesNet detection labelled reptile / amphibian / insect (class or order: squamata, anura, caudata, lepidoptera, odonata, …) → BioCLIP over that group's list. Generic "animal"/"unknown" detection → BioCLIP over all three lists + background prompts. **No detection at all** (typical for insect and frog macros) → whole-frame BioCLIP over all three lists + 20 background prompts ("a photo of a plant", "a landscape photo", "a photo of a bird", …), tagged only if the species beats every background prompt **and** passes the threshold. Reptile and amphibian detections are scored over both herp lists together, because SpeciesNet called a juvenile newt a "reptile". When several groups compete, BioCLIP picks the group with the most total probability, then the best species inside it. Mammals stay on SpeciesNet. The BioCLIP routes work even with Kestrel's "wildlife" toggle off; mammals still need it on. The region is the bird model's region; North America uses World lists. |
| Keywords | `Reptiles\|English\|Latin`, `Amphibians\|…`, `Insects\|…`, plus SpeciesNet `Mammals\|English\|Latin` (Latin from SpeciesNet's labels). Same `_Check`, digiKam `/` and merge rules as birds. |
| Manual edits | Kestrel records, per file and root, the tags it last wrote (`.kestrel/kestrel_keyword_state.json`). If the file's tags under a root now differ, you edited them, so that root is left alone. **Settings → Overwrite my manual species edits** forces an overwrite. Editing a sidecar also triggers Kestrel's existing "changed outside Kestrel, overwrite?" question; the protection applies after you confirm. Species you set by hand in Kestrel (finalized scene tags) are written as confident, never `_Check`. |
| Settings | **Species keyword confidence** 0.30–0.99 (default 0.75), shared by birds and BioCLIP. **Other wildlife model**: BioCLIP 2 (default; falls back to SpeciesNet with a message if the files are missing) or SpeciesNet only. **Overwrite my manual species edits** (off). Bird model default is now **UK**. |
| Picker | The species picker also offers BioCLIP species from the current region's lists (searched after birds), so a wrong reptile/amphibian/insect ID can be corrected by hand. |

### Installing BioCLIP on Windows

1. Copy the whole `bioclip-2` folder (`config.json`, `image_encoder_fp32.onnx`, `README.txt`,
   `embeddings\`) into `%LOCALAPPDATA%\BirdtagDesktop\models_extra\bioclip-2\`, next to the
   EVA-02 file. Check the SHA256 in `README.txt`.
2. Settings → Species & Region → Other wildlife model → **BioCLIP 2**. The line below the setting
   shows the species counts it found for your region.
3. To rebuild or extend the lists (e.g. World), with Python plus `torch open_clip_torch onnx onnxruntime`:
   ```
   python tools\uk_models\export_bioclip.py --out D:\kestrel-models --images <a few test JPEGs>
   python tools\uk_models\build_bioclip_lists.py --out D:\kestrel-models\bioclip-lists --regions world
   python tools\uk_models\build_bioclip_embeddings.py --lists D:\kestrel-models\bioclip-lists\lists --model-dir D:\kestrel-models\bioclip-2 --only world
   ```
   GBIF answers about 5–10 requests/s, so the World lists (~25k species) take about an hour to
   fetch (cached and resumable). Encoding runs at roughly 5–10 prompts/s on 2 CPU cores and much
   faster on a desktop CPU or GPU.

## Known limitations

* **DirectML not tested here** (the build machine is Linux, CPU only). The export uses the
  legacy TorchScript exporter at opset 17 with plain MatMul/Softmax attention, the same
  route Kestrel uses for its DirectML-safe `mdv1000-cedar` detector. If DirectML still
  fails, Kestrel's coordinator falls back to CPU automatically.
* **Speed**: EVA-02 Large is about 5 s per bird on 2 CPU cores (fp32). On a GTX 1050 Ti
  expect well under 1 s. It is far heavier than the original 300 px model.
* **Confidence is relative to the region**: the softmax only covers the selected
  region's species, so scores in UK mode are higher than World-mode scores for the same image.
* 49 regular UK species are not in iNat21 at all (see the build script's output), and
  10 iNat21 birds have no IOC catalogue entry (they keep the iNat name; lookups for them
  return nothing, as for any unknown name).
* "Europe" means the IOC Palearctic (`PAL`) + Atlantic (`AO`) + cosmopolitan species. IOC
  v15.1 has no finer Europe code, so some East-Asian Palearctic species are included.
* The confident/`_Check` split uses the model score sent from the culling window. A
  species changed by hand in the scene view is not flagged separately, so it keeps the
  original model score.
* The heron test image scores 0.69 in UK mode, so it gets `Birds|_Check|Grey Heron`.
  If that happens often, lower the threshold (`species_threshold` in
  `write_xmp_metadata`, default 0.75).
* The Kestrel database stores IOC names ("European Robin"); only keywords use BOU names.
* Phase 2 protects manual edits only for files Kestrel has written before (with a state
  record). On the first Kestrel write, existing `Birds|…` tags (e.g. from birdtag) are replaced,
  as birdtag itself does.
* **BioCLIP fp16 not shipped**: ONNX Runtime 1.23 (CPU) crashes loading the half-precision graph,
  so parity could not be checked. fp32 is 1.2 GB; on a 4 GB card with EVA-02 fp16 (0.6 GB) and
  SpeciesNet it should fit, and Kestrel falls back to CPU if it does not.
* **World BioCLIP lists not built here** (GBIF throughput on this machine); the commands are above.
  UK and Europe embeddings are built and listed with SHA256 in `bioclip-2/README.txt`.
* Bigger regions mean more look-alikes. In Europe mode, the UK toad photo comes out as Caucasian
  Toad 0.49 (below threshold, so untagged); the peacock is still correct at 1.00. Use UK
  mode for British photos. The UK exclusion list only applies to the UK lists.
* BioCLIP zero-shot is less accurate than a trained classifier, especially for small or
  similar insects (many hoverflies, micro-moths, beetles) and newts. Look at `_Check` tags.
  Parasites whose photos show their hosts can win (the toad fly, the ladybird wasp); add any
  you meet to `tools/uk_models/data/uk_exclude.csv` and rebuild the UK embeddings.
* Tight macro shots that MegaDetector misses only get a species from the whole-frame route
  if it clears the threshold; otherwise you tag them by hand (the picker lists BioCLIP species).
* The picker shows BioCLIP species with their group (e.g. "Insects") as the family line;
  family pills for them use the scientific family name.
* A scene's manual species is applied to every image in that scene (Kestrel stores one
  species per image in XMP); scenes with several species use the first.
